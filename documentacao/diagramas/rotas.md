# Rotas Flask do Chocomilka

| Operação | Método | Rota | Função |
|---|---|---|---|
| Listar produtos | GET | `/produtos` | Retorna todos os produtos |
| Cadastrar | POST | `/produtos` | Insere um produto |
| Consultar um | GET | `/produtos/<id>` | Retorna um produto |
| Atualizar | PUT | `/produtos/<id>` | Altera os dados |
| Excluir | DELETE | `/produtos/<id>` | Remove um produto |
